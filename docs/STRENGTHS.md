# 项目优势清单与答辩要点（LUT-SA / 鸿蒙玲珑核）

> 用途：作品说明文档收尾、演示视频脚本、PPT、线下答辩。每条优势按「主张 → 证据 → 对应赛题口径 → 一句话话术」组织。
> 评分维度参考：创新性 ~50 / 完备度 ~20 / 前景评估 ~20 / 规范性 ~10 / 附加"实际应用价值" ~20。

## 一、五个突出优势（按评分权重排序）

### 优势 1｜硬核技术：2.44 BPW 比特级查表（LUT）内核 —— 直接命中"提升系统 AI 任务运行效率"
- **主张**：用"查表 + 整数累加"替代"反量化 + 浮点乘加"，从算子层消除低比特模型的带宽浪费
- **证据（全部实测）**：
  - 内核自测 **PASS**、内核基准 **200 次 1.41–1.56 ms（7.1–7.8 µs/次）**，覆盖 **x86_64 AVX2 与 arm64 NEON 双架构**
  - 跨平台对照 llama.cpp 反量化基线：**2.5–5.9×**（树莓派 5 单核最高 5.9×，**设备越弱优势越大**）
  - 模型 986 MB（2.44 bit）＝ 同源 fp16 的 **1/6.6**
- **口径**：赛题 2.1"提升系统 AI 任务运行效率" + 2.2"技术亮点"
- **话术**：*"别人是把低比特模型跑起来，我们改的是跑法——比特直接当表下标，省掉整条反量化路径。"*

### 优势 2｜独家算法：链式 KV 记忆调度 —— 逐字命中 2.2"端侧记忆调度"
- **主张**：把 LLM 的 KV 缓存当"系统记忆"来调度：跨轮维护记忆链 + 最长公共前缀复用 + 分歧精确裁剪
- **证据（全部实测）**：
  - 同提示二轮：TTFT **239.78 → 0.57 ms**（模拟器）/ **248.80 → 1.15 ms**（真机），**降幅 216×**
  - 前缀处理（prompt eval）**归零**；**部分复用 6 of 13**（追加式提问）证明是通用 LCP 算法，不是"整轮缓存"的粗糙做法
- **口径**：赛题 2.2"端侧记忆调度"（原文命中）+ 2.3 案例①"首字响应（TTFT）系统级加速"
- **话术**：*"多轮对话里重复的那半句，我们不会再算第二遍——首字延迟从 240 毫秒掉到 1 毫秒。"*

### 优势 3｜系统友好：L2 感知调度闭环，有对照组的数据
- **主张**：前后台感知驱动引擎释放/预热，用 60 s 滞回保护记忆链不被频繁切换冲掉
- **证据（教科书级 A/B）**：调度开启：后台 70 s 进程内存 Pss **1370 → 71 MB（释放 1.30 GB）**，回前台自动重载 1.37 s；**关闭调度（对照）：1356 MB 不变**
- **口径**：赛题 2.1"感知数据流处理机制" + "系统资源调度"
- **话术**：*"一个后台的 AI 应用不该攥着 1.3 GB 内存不放——我们让它自己还回去，并且开关一拨就能复现这个对照。"*

### 优势 4｜可落地性：交付版真机实测，不是"跑个 demo"
- **证据**：真机（Pura 70 Pro / API 24 / arm64）**交付版 HAP** 完成安装 → 冷启动加载 1.09 s → 生成 20.39 tok/s → 二轮 TTFT 1.15 ms → 峰值内存 1413.6 MB → 后台释放 → 内核自测/基准；官方模拟器同步复现（23.35 tok/s）
- **交付质量**：三闸门（安装/启动/渲染）+ 离线验签 + 源码自包含（引擎内嵌，评委免联网）+ 命令行可复现构建
- **口径**：附加"实际应用价值" + 完备度 + 规范性
- **话术**：*"我们的数字都是在交付版安装包上跑出来的，评委拿到的那个 HAP 就是产生这些数字的那个包。"*

### 优势 5｜技术纵深 + 边界研究：双形态与平台边界实测
- **主张**：同一引擎两种形态——应用级（已交付）与系统服务级（预研，qemu 全链路 PASS）
- **独家研究结论**：实测确认零售版 HarmonyOS **不允许第三方注册系统服务**（六条锁：非 root、SELinux Enforcing、系统分区只读且 profile/init 不可访问、`hdc target mount` 要求 debug 镜像、两套 SDK 均无 samgr 头文件、无 SA 管理工具）
- **口径**：完备度 + 技术亮点 + 答辩抗压
- **话术**：*"我们把系统服务形态做到了能做的最后一步，并把'为什么在零售机上落不了地'变成了可复现的实测结论——这是平台边界，不是实现缺陷。"*

## 五、如果只讲三句话（电梯版）

1. **改的是跑法**：2.44 bit 查表内核，同设备同模型比反量化路径快 2.5–5.9×，内核调用 7.8 微秒。
2. **记忆会调度**：跨轮复用前缀，重复提问的首字延迟 240 毫秒 → 1 毫秒（216×）。
3. **系统能回收**：后台自动归还 1.30 GB（对照组 0），交付版真机三闸门全过。
