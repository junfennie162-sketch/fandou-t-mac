# 项目优势提炼（LUT-SA / 鸿蒙玲珑核 · 终版）

> 用途：作品说明文档、PPT、演示视频脚本、线下答辩。每条 = **主张 → 证据 → 赛题口径 → 一句话话术**。
> 评分维度：创新性 ~50 / 完备度 ~20 / 前景 ~20 / 规范性 ~10 + 附加"实际应用价值" ~20。

## 优势 1｜硬核技术：2.44 BPW 比特级查表（LUT）内核
**主张**：用"查表 + 整数累加"替代"反量化 + 浮点乘加"，从算子层消除低比特模型的带宽浪费。

| 证据 | 数值 |
|---|---|
| 内核自测 | **PASS**（zero-in ⇒ zero-out），**x86_64 AVX2 与 arm64 NEON 双架构** |
| 内核基准（200 次） | 模拟器 **1.41 ms（7.1 µs/次）**；真机 **1.56 ms（7.8 µs/次）** |
| 跨平台对照（vs llama.cpp 反量化，同模型同线程） | **2.5–5.9×**（树莓派 5 单核最高 **5.9×**，设备越弱优势越大） |
| 模型体积 | 986 MB（2.44 bit）= 同源 fp16 的 **1/6.6** |

**赛题口径**：2.1 "提升系统 AI 任务运行效率" + 2.2 "技术亮点"
**话术**：*"别人是把低比特模型跑起来，我们改的是跑法——比特直接当表下标，省掉整条反量化路径。"*

## 优势 2｜独家算法：链式 KV 记忆调度
**主张**：把 KV 缓存当"系统记忆"调度——跨轮维护记忆链 + 最长公共前缀复用 + 分歧精确裁剪。

| 证据 | 数值 |
|---|---|
| 完全复用（同提示二轮） | 复用 **6/6（模拟器）/ 8/8（真机）**；TTFT **239.78 → 0.57 ms**、**248.80 → 1.15 ms**（降幅 **216×**） |
| 部分复用（追加式提问） | **复用 6 of 13**（前缀 6 复用 + 增量 7 解码）→ 通用 LCP 算法，非"整轮缓存" |
| 前缀处理 | prompt eval **归零**（复用命中段不重算） |

**赛题口径**：2.2 **"端侧记忆调度"（原文命中）** + 2.3 案例①"首字响应（TTFT）系统级加速"
**话术**：*"多轮对话里重复的那半句，我们不会再算第二遍——首字延迟从 240 毫秒掉到 1 毫秒。"*

## 优势 3｜系统友好：L2 感知调度（有对照组的系统级实验）
**主张**：前后台感知驱动引擎释放/预热，60 s 滞回保护记忆链。

| 证据（同设备、同模型、同后台时长，唯一变量=开关） | 数值 |
|---|---|
| 调度开 | Pss **1370 MB → 71 MB（释放 1.30 GB）**→ 回前台自动重载 1.37 s → 1364 MB |
| 调度关（对照） | **1356 MB → 1356 MB（不释放）** |
| 快速切回（<60 s） | 引擎与 KV 链保持（×3 次实测，日志实证） |

**赛题口径**：2.1 "感知数据流处理机制" + "系统资源调度"
**话术**：*"一个后台的 AI 应用不该攥着 1.3 GB 不放——我们让它自己还回去，而且开关一拨就能复现这个对照。"*

## 优势 4｜可落地性：交付版真机实测（不是"跑个 demo"）
**证据**：真机（HUAWEI Pura 70 Pro / HBN-AL00 / API 24 / arm64）**交付版 HAP** 全链实测：
安装成功 → 冷启动加载 **1.09 s** → 生成 **20.39 tokens/s** → 二轮 TTFT **1.15 ms** → 峰值内存 **1413.6 MB**（hidumper 交叉核验 Pss 1393 MB）→ 后台释放 → 内核自测/基准 PASS。
配套：**三闸门**（安装/启动/渲染）+ 离线验签 + 源码自包含（引擎内嵌，评委免联网）+ 命令行可复现构建。
**赛题口径**：附加"实际应用价值" + 完备度 + 规范性
**话术**：*"这些数字就是在评委手里那个 HAP 上跑出来的。"*

## 优势 5｜输出质量：采样器工程化（本轮新增）
**主张**：自研采样器补齐重复惩罚与核采样，修掉"复读机"退化。

| 证据（同提示 A/B） | 输出 |
|---|---|
| 升级前 | `…the city of Paris. It is the most visited city in the world attracts millions of tourist every year from every corner of the world and attracts millions of…`（复读） |
| **升级后** | `the city where all things French are made. From the bistros with crêpes and croissants, to the boutiques brimming with Chanel`（通顺、零复读） |

配置：`top_k=40 / top_p=0.95 / temp=0.8 / repeat_penalty=1.15 (last_n=64)`，报告页输出真实参数（口径诚实）。
**话术**：*"端侧推理不只要快，还要能读——我们把采样策略也当作交付质量的一部分来调。"*

## 电梯版三句话

1. **改的是跑法**：2.44 bit 查表内核，同设备同模型比反量化路径快 2.5–5.9×，内核调用 7.8 微秒。
2. **记忆会调度**：跨轮复用前缀，重复提问的首字延迟 240 毫秒 → 1 毫秒（216×）。
3. **系统能回收**：后台自动归还 1.30 GB（对照组 0），交付版真机三闸门全过，输出通顺可读。
