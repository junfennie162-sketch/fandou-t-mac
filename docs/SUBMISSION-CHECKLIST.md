1. **剔除 ASan**：DevEco 的 Run 会注入 `-p ohos-debug-asan=true`（`__asan_*` 全量插桩 + 依赖 `libclang_rt.asan.so`）。CLI 纯净构建后同机同模型 **10.5 → 25.01 tok/s（2.4×）**。
